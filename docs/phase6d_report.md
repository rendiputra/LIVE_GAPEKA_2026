## Q4 — why TBT looked like it rose

The harness claimed to stub tiles with `page.route`, but Lighthouse opens its **own** tab, so the route never applied. The run fetched real OSM tiles over a throttled 1.6 Mbit link, and TBT measured tile download and decode rather than application work.

| Run | Tiles | Performance | TBT |
|---|---|---|---|
| tiles NOT blocked (old behaviour) | fetched from network | 71 | 3279 ms |
| tiles blocked (fixed harness) | never fetched | **76** | **1220 ms** |

Fix: `blockedUrlPatterns` (a Lighthouse setting, not a page route). No application code changed. Blocking makes two numbers read lower than they are in a real deployment — best-practices (console errors from the blocked fetches) and CLS (no tile layout shift) — so take those from the unblocked run.
