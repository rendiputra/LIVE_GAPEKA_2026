## F2 — train names

Root cause: `export_web` read `SELECT trip_id, train_no, relation` and used the train number as the name, so every trip rendered as "KA 50 — 50". The database was always correct (625/625 trains have a real name). The export now reads `trains.name`.

## F3 — basemap at z6-7

The extracted tiles carry `places` features with `kind`, `min_zoom` and `name:id`, and the bundled style filters on those same fields, so style and extract agree. z6-7 is coarse by design: the coastline comes from Natural Earth and each tile holds about one locality. The fix is a closer default zoom (7.2) plus our own rail layer, not extra zoom levels.
