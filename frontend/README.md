# frontend/ — Gapeka 2026 static site (clean-room revamp)

A separate, from-scratch frontend. `web/` remains the Phase 6 baseline and is not
touched; this tree replaces it milestone by milestone.

## Status

| Milestone | State |
|---|---|
| 1 — scaffolding, export hook, ADRs | done |
| 2 — pure TS engine + Web Worker + 6,000-frame parity gate | done |
| 3 — map, layer switcher, live motion | done |
| 4 — Train Inspector, Station Board, Search, dock, Tentang | done |
| 5 — motion polish, mobile, perf gates | not started |

## Commands

Run from the repository root:

```bash
make export-frontend   # schedule -> frontend/public/data (gitignored)
make frontend-test     # Vitest: unit + the 6,000-frame parity gate
make frontend-dev      # Vite dev server
make frontend-build    # static bundle into frontend/dist
make frontend-e2e      # Playwright (no specs until Turn 3)
```

## Layout

```
src/engine/     pure TypeScript port of engine/position.py — no DOM, no Intl
src/worker/     Web Worker: fetch, decode, positions_at, GeoJSON
public/data/    exported schedule (gitignored)
```

## The parity gate

`src/engine/parity.test.ts` replays all 6,000 frames of
`engine/parity_frames.json` (generated by `make parity`) and requires them to
match `engine/position.py` within 1 m / 0.2 km/h, with status and next-stop
fields exact. **Zero tolerated failures.** `engine/position.py` is the reference;
if the port disagrees, the port is wrong.

## Decisions that differ from `web/`

- **ADR 002 amendment (2026-11-23):** no preview banner and no footer disclaimer
  bar. A persistent `Live (Estimasi) · HH:MM WIB` status pill states the estimate
  status; the full disclaimer, effective date, data hash and attribution live in
  the "Tentang" modal. The `preview_banner` string is not exported here at all.
- **ADR 010:** OpenFreeMap vector tiles (`positron` default, `liberty`
  selectable) instead of self-hosted PMTiles. OpenRailwayMap `Infrastruktur` and
  `Max Speed` overlays are available, both OFF by default.
- **ADR 011:** the Web Worker loads the schedule; positions are computed off the
  main thread.
